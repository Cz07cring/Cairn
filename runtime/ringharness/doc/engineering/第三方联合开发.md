# 第三方联合开发

面向要在 Ringharness 之外联合交付的团队：Harness 上游、Temporal 运维、Verifier 实现方、模型服务、对象仓/Git 适配等。

## 1. 权威切分（必须遵守）

| 职责 | 权威 | 第三方可做 | 禁止 |
|---|---|---|---|
| Goal/Task 状态、DONE、预算、审批、证据验收 | Kernel / 业务 PG | 经公开或内部 API 提交 outcome / receipt | 直连业务库改状态；用 Workflow COMPLETED 冒充 DONE |
| 等待、计时、投递、技术重试 | Temporal | 提供兼容 Server；Worker 实现具名 Activity | Temporal 不可用时静默切 LEGACY 调度 |
| 模型会话 / Skill 固定版本 | Runner + 钉扎 Harness | 按固定 SHA 提供 checkout；实现 `RunActivation` | 自建第二套业务状态机；持业务 DB 写凭据 |
| 工具执行与沙箱 | ExecutionBroker | 实现受控工具；回报 TrustedReceipt | 绕过 Kernel 的 effect 准入 |
| 字节完整性 | Evidence Ledger / S3 | 提供兼容对象仓 | 用未登记字节冒充 PASS |

规格：`doc/v0.6/`（编排修订）+ 继承的 `doc/01`–`doc/10`。进度：`doc/implementation/进度与验证.md`。

## 2. 推荐协作方式

1. 在 GitHub 开 **「第三方集成」** Issue（模板 `.github/ISSUE_TEMPLATE/integration.yml`），写清上游 URL/SHA/digest。
2. Fork 或被加为 Collaborator → 功能分支 → PR；CI 见 `.github/workflows/foundation.yml`。
3. 契约变更走 `scripts/generate_contracts.py`；消费方使用 `@ring/api-client`（生成物，勿手改）。
4. 版本钉扎写入 `deploy/temporal/VERSIONS.md` / `contracts/orchestration/VERSION_MATRIX.md`（或 PR 内等价清单）；**禁止 latest**。

## 3. 集成接触面（当前）

| 接触面 | 位置 | 说明 |
|---|---|---|
| 公共/内部 HTTP | OpenAPI → `packages/api-client` | JWT Bearer；缺配置失败关闭 |
| TEMPORAL 具名准入 | `POST /internal/v1/runtime/admit`、`GET …/runtime/actions` | 全局 `claims` 对 TEMPORAL Goal 禁用 |
| 编排投递 | `orchestration_deliveries` + Relay | PENDING→ACK；Unavailable 不翻 LEGACY |
| TS Activity | `RunActivation` @ task queue `ring-runner` | PLAN 可走 Cordis 零工具桥；需 Control URL + worker JWT |
| Python Worker | `apps/workflow-worker` | queue `ring-control`；Kernel Activities |
| Broker poll | `GET /internal/v1/broker/effects` | 仅本 worker 租约下 PREPARED/AUTHORIZED |
| Harness pin | `apps/runner` + `RING_HARNESS_CHECKOUT` | 固定 SHA，见 `doc/09` / v0.6/09 |

本机 Temporal 模板：`deploy/temporal/`（与业务 PG 隔离）。开发机模型优先本地 Qwen（PM2），见 AGENTS.md §9。

## 4. 联调检查清单

- [ ] 上游版本精确 pin（commit / 镜像 digest）
- [ ] 身份：独立 worker JWT；无业务库写 URL 进入 Runner/第三方进程
- [ ] TEMPORAL Goal：无全局 claim；仅 admit
- [ ] 副作用：先 EffectIntent/ModelInvocation，再执行；回执幂等
- [ ] 停止：StopReceipt `EXITED∧compute_released` 才释放隔离资源
- [ ] 验收：VerificationRun/义务/Audit；不得缺 run 仍 DONE
- [ ] CI / `scripts/test_local.py` 相关用例绿或明确 skip

## 5. 许可证与保密

仓库默认按维护者发布策略。若联合开发涉及私有上游或客户数据，使用 **private** 仓库 + 最小 Collaborator 集；勿把客户密钥写入 Issue/PR。
